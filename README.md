# Keyboard Mic Bridge · 键盘语音兼容

让 MacBook 内置麦克风与小米遥控器共用 SayAll 的 `MiRemoteV 2ch`，继续使用豆包输入法识别文字。

**当前为实验性交接版本（2026-11-11）。键盘 Fn 仍会偶发失效，尚未找到完整根因，不能当作稳定版。** 曾通过长按、点按持续及超过一分钟出字测试，之后故障再次出现；停用再启用曾恢复一次。

## 音频链路

```text
小米遥控器麦克风 → SayAll ───────────────────┐
                                          ├→ MiRemoteV 2ch → 豆包输入法 → 文字
MacBook 内置麦克风 → Keyboard Mic Bridge ───┘
                        ↑
                 Fn 控制；读取 SayAll 日志避让遥控器
```

本项目只转发声音，不做语音识别，不保存音频，不联网，不设置开机启动，不改系统默认音源。用户明确不接受本地语音识别方案。

## 使用条件

实际使用环境：Apple Silicon MacBook Air、macOS 26.6.2、小米遥控器 2 Pro（RC003-MS）、SayAll 1.9.21（build 174）、豆包输入法。其他系统和设备未经验证。代码按名称寻找包含 `MacBook` 与 `麦克风` 的输入设备，以及精确名为 `MiRemoteV 2ch` 的输出设备；英文系统或其他麦克风可能不匹配。

先自行安装 SayAll、其虚拟音频设备与豆包输入法，并连接遥控器。本包不附带这些产品的安装程序。豆包输入源设为 `MiRemoteV 2ch`，长按与点按语音快捷键均设为 Fn。

## 从源码构建

需安装 Apple Command Line Tools（提供 Swift 编译器）；无第三方依赖。

```sh
bash scripts/build.sh
```

脚本在临时目录构建、执行状态机自检、临时签名并验证，输出 `dist/KeyboardMicBridge-experimental.zip`，不启动应用、不修改权限。可单独运行 `bash scripts/test.sh` 只编译和执行状态机自检。

解压构建包，将唯一的一份 `KeyboardMicBridge.app` 放在固定位置，再打开并启用。首次需要用户在系统设置允许“麦克风”与“输入监控”。应用没有 Apple 公证；不要关闭系统安全机制来绕过阻止。重新编译或移动应用可能需要重新授权。不要同时运行多个版本。

## 操作

| 动作 | 本工具行为 |
|---|---|
| 长按 Fn | 开始转发电脑麦克风，松开停止 |
| 短按 Fn（小于 300ms） | 持续转发；再按 Fn、任意键或点鼠标就停止，和豆包一致（滚轮不算） |
| 遥控器开始收音 | 电脑转发停止；遥控器结束后需再次按 Fn |
| 菜单栏图标 | 斜杠麦克风＝停用，空心＝待命，红色实心＝收音中，电波＝遥控器在用；点开菜单可开关、自检、退出 |
| 睡眠／会话失活 | 停止当前收音，保持启用 |

启动即自动启用（已授权时），没有窗口。待命时不占虚拟通道、不开麦克风（实测约 20–28 MB 内存、CPU 约 0）；第一次按 Fn 才接上 MiRemoteV 2ch，用完 60 秒没再用就自动松开，连续使用时不必反复重连。图标由 `scripts/make-icon.swift` 生成。中途出错只结束这一次收音，不再整体停用；再按 Fn 即重试。

Fn 长按约 200ms 后才有收音意图，还需等待采集启动；遥控器切换有约 400ms 避让。过早说话可能丢首字。持续转发有 30 分钟保护上限。

**点按模式和豆包同步结束：** 任意键（回车上屏、其他键取消）或点鼠标都会让豆包和本工具一起结束。只有用其他方式结束豆包（如等它超时）时可能不同步，看菜单栏图标，按一下 Esc 即可对齐。

“虚拟麦克风通道自检”会停用桥接并向虚拟设备发送测试音，验证虚拟回环，不验证真实麦克风、Fn 或豆包出字；请先退出正在进行的语音输入。

## 文件与版本

- `src/KeyboardMicBridge.swift`：当前交接源码，包含最后一次切换避让修正；用户仍报告失效。
- `resources/Info.plist.template`：应用元数据，沿用测试版 bundle ID，避免无谓变更权限身份。
- `releases/initial-user-tested.zip`：曾由用户确认成功的原版二进制，不能据此证明长期稳定。
- `releases/latest-experimental.zip`：最后使用的优化实验版，已知仍有间歇故障。
- `archive/KeyboardMicBridge-before-selfheal.swift`：2026-11-11 自愈改版前的源码。
- `archive/KeyboardMicBridge-before-opt.swift`：优化前源码快照；未验证与原版 ZIP 完全对应，不能视为可重复构建配对。
- `dist/`：从当前源码新构建的包；与旧 ZIP 不保证逐字节相同。

历史 ZIP 原样保留，可能含 macOS `._` 元数据；未将外部软件、录音、原始运行日志、账号配置纳入交接。原工作目录和正在运行的应用不因打包而改动。
